检查采集与分页、异常保存、取消流程、SQLite 保存、清洗与匿名导出、分析与图表入口、报告产物及 Git 提交边界。检查采用核心源码审阅、全量自动测试、离线流程和隐藏界面冒烟；本轮及前序真实评论采集复测共同提供证据。未发现阻止本次提交的已知问题；这不是无缺陷保证。

## 修复

- 翻页失败保留此前成功页，错误类别与停止原因写入结果和研究日志；pipeline 保存部分数据并标记 partial。
- 首屏业务或解析错误进入备用接口；登录失效、风控及限流/网络重试耗尽时停止本轮。
- 自动时间排序优先使用支持排序的后端；降级时保留排序未生效说明。
- 一级、二级评论同页去重；一级分页游标按 ID 和类型共同识别，二级分页防止重复游标空转。
- 时间覆盖统计只计实际保留的窗口内评论，避免目标截断后数量与范围虚增。
- 二级评论失败或预算耗尽保留已有回复并标记未完成。
- 采集分页间响应停止请求；用户停止后不再自动启动分析。已启动的分析仍需等待当前任务结束。
- 修复连续绘图时中文字体被 Seaborn 重置、局部变量未定义又被异常处理吞掉的问题。
