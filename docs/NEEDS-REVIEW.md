## 三、以后怎么复查（不用你填表）

改了提示词或换了模型之后，跑这个就能自动挑出"模型自己都拿不准"的样本：

```bash
python tools/make_review_sheet.py --run <会话ID> --mode disagreement
```

它只抽**两个通道判断不一致**的样本，数量少（通常 10 条以内）。
你看一眼、判断"模型对不对"，比逐条读 20 条快得多。

> 说明：这张表**不能**用来算准确率（它故意过采样了最可能错的样本）。
> 它的用途是"发现系统性问题"，不是"评估质量"。质量已经有 40 条的人工结论作底。
